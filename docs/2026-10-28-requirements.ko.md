# AI Co-worker Without Me 요구사항 (초안, 2026-10-28)

## 무엇을 만드나

동료끼리 각자 쓰는 AI(Claude Code, Codex)가 직접 묻고 답하게 해 주는 MCP다.

지금은 사람이 AI 결과를 복사해 메신저로 보내고, 받은 사람이 그걸 다시 자기 AI에 붙여넣는다. 이 반복을 없앤다. AI끼리 주고받는 동안 사람은 지켜보고, 끝나면 합의문을 놓고 논의한다.

## 쓰는 사람과 환경

- 각자 개인 계정으로 쓰는 Claude Code(Pro·Max)와 Codex. 회사 Team·Enterprise 계정은 대상이 아니다.
- Mac과 Windows 모두 된다. Windows에서 신경 쓸 것은 셋이다.
  - **방화벽 허용 창:** 처음 포트를 열 때 Windows 방화벽이 허용할지 묻는다. 「개인 네트워크」로 허용해야 한다.
  - **`컴퓨터이름.local`:** Windows에서는 이 이름으로 찾기가 잘 안 될 수 있다. 그래서 연결 코드에 IP 주소를 항상 함께 넣는다.
  - **WSL 안에서 Claude나 Codex를 돌리는 경우:** WSL은 기본 설정에서 바깥과 다른 네트워크에 있어서 밖에서 그 포트로 들어올 수 없다. WSL 네트워크를 미러 모드로 바꿔야 한다.
- **1차는 사내망과 회사 VPN이다.** VPN으로 들어온 PC도 사내 IP를 받으므로 사내망과 같게 다룬다. 동료 PC에 Tailscale을 깔 수 없어서 Tailscale은 전제로 하지 않는다.
- **2차는 외부망이다.** VPN 없이 서로 다른 공유기 아래에 있는 PC끼리는 바로 연결되지 않아서, 중간에서 이어 주는 방법이 필요하다. 그 방법은 2차에서 정한다.
- **사내 방화벽과 VPN에서 PC끼리 통신이 되는지 확인해야 한다.** 사내망은 「기본 차단, 필요한 통신만 허용」으로 운영되는 경우가 많다. 그러면 PC끼리 이 포트로 통신하는 것을 허용 목록에 올려야 한다. VPN도 서버만 열어 두고 PC끼리는 막는 경우가 있다.
- 2026-10-28에 같은 Mac 안에서 실제 Codex 세션이 브릿지를 열고, 실제 Claude Code 세션이 연결 코드로 붙어 질문하고 답을 받고 닫기까지 성공했다. Codex는 자기 폴더의 메모를 읽고 답했고, 상대가 닫자 스스로 기다리기를 멈췄다. 끝난 뒤 열린 포트와 남은 파일은 없었다.
- 2026-10-28에 집 Mac과 회사 Mac mini 사이를 Tailscale로 연결해 봤다. 다른 네트워크에 있는 IP로 접속하는 상황이 VPN과 같아서, Tailscale은 개발 중 시험에만 쓴다.
- 2026-10-29에 같은 Mac 안에서 Channels로 켠 실제 Claude Code(2.1.312) 세션이 연결 코드로 붙었다. 상대가 보낸 질문이 세션에 바로 들어왔고, AI는 기다리기 도구를 부르지 않고 6초 만에 답했다. 상대가 닫은 것도 바로 알았다.
- 2026-10-29에 Channels 없이 켠 Claude Code 세션도 시험했다. 상대가 2분 30초 뒤에 질문했는데, 그사이 Claude Code가 기다리기 호출을 백그라운드로 넘겼다가 질문이 오자 알렸고, AI가 7초 만에 답했다.
- 같은 시험에서 작은 모델(Haiku)이 긴 연결 코드를 옮겨 적다 공개키 한 글자를 틀린 일이 있었다. 상대는 그 코드를 거절했고, 사람에게는 「이미 쓴 코드이거나 만료됐다」는 엉뚱한 오류가 갔다. 그래서 연결 코드 끝에 확인용 글자를 붙였다. 잘못 옮긴 코드는 상대에게 보내기 전에 「잘못 옮겨졌다」고 알린다.
- 2026-10-29에 집의 Windows PC(Claude Code 2.1.312, Bun 1.3.7)에서 Channels로 켠 Claude Code 세션이 같은 네트워크의 Mac에 있는 상대와 연결 코드로 붙었다. 상대가 보낸 질문이 세션에 바로 들어왔고, AI가 6초 만에 답했다. 전체 시험 37개도 Windows에서 모두 통과했다. 이 시험에서 고친 것이 둘이다.
  - 그 PC의 bun은 chocolatey가 까는 껍데기(`bun.exe`)를 거쳐 실행돼, MCP 바로 위가 Claude Code가 아니라 껍데기로 잡혔다. 그대로면 채널 모드를 알아보지 못했다. 이제 셸과 bun 껍데기는 건너뛰고 그 위를 본다.
  - PowerShell을 단계마다 새로 띄워 실행 인자를 읽는 데 7초가 걸렸다. 프로세스 목록을 한 번에 받아 따라가게 바꿔 0.8초로 줄였다. Claude Code가 띄운 MCP(`CLAUDECODE=1`)가 아니면 아예 읽지 않는다.

## 흐름

1. 사람이 자기 Claude나 Codex 세션에서 브릿지를 연다. 그 세션의 MCP가 포트를 열고 연결 코드를 보여 준다.
2. 사람이 연결 코드를 메신저로 동료에게 보낸다. 동료가 자기 세션에 코드를 넣으면 두 세션이 연결된다.
3. 연결되면 양쪽 AI는 사람이 「그만」이라고 할 때까지 계속 듣는다. 한 번 주고받고 끝나지 않는다.
4. 양쪽 다 질문하고 답한다.
5. 질문을 받거나, 답하거나, 답을 받을 때마다 AI가 그 세션에서 바로 사람에게 정리해서 알린다. 누가, 무엇을 물었고, 무엇을 답했고, 사실에서 나온 답인지 사람이 정한 답인지를 적는다.
6. 이미 정해진 것(코드, 문서, 이미 내린 결정, 사람이 이미 말한 것에 답이 있는 것)은 AI가 바로 답한다.
7. 결정이 필요한 것(선택지 중 고르기, 우선순위, 범위, 일정 등)은 AI가 정하지 않는다. 상대에게 「사람에게 확인 중」이라고 알리고, 자기 사람에게 선택지와 추천을 붙여 묻는다. 사람이 정하면 그 결정을 답으로 보낸다.
8. 끝나면 AI가 합의문을 쓴다. 합의문에는 결론, 확인한 사실과 근거(파일·실행 결과), 추측, 의견이 갈린 점, 사람이 정해야 할 것을 나눠 적는다.

## 연결 구조

중앙 서버가 없다. 세션끼리 직접 연결한다.

- **브릿지는 세션별로 연다.** MCP는 모든 세션에 들어 있지만, 사람이 브릿지를 연 세션만 포트를 연다. 세션이 닫히면 포트와 연결도 끝난다.
- **포트는 직접 지정할 수 있다.** 지정하지 않으면 정해 둔 범위(예: 7700~7799)에서 비어 있는 번호를 쓴다. 범위를 정해 두는 건 사내 방화벽에 허용을 요청하기 쉽게 하려는 것이다. 한 PC에서 세션 여러 개가 브릿지를 열면 각자 다른 포트로 뜬다.
- **연결 코드에는 주소 목록, 포트, 암호화용 공개키가 들어 있다.** 주소 목록은 사내 IP, VPN 주소, `컴퓨터이름.local`이다. 받는 쪽은 앞에서부터 차례로 시도한다.
- **연결 조합은 자유롭다.** 내 Claude와 동료의 Codex를 연결할 수 있고, 같은 PC 안의 Claude와 Codex도 연결할 수 있다. 한 세션이 여러 세션과 동시에 연결될 수도 있다.
- **같은 프로젝트를 하는 사람들은 그룹으로 묶인다(2026-10-29 추가).** 연결 코드는 기본이 그룹 코드다. 코드로 들어온 세션은 코드를 준 세션의 그룹 전체에 소개되어 서로 연결된다. 소개받은 세션끼리는 코드 없이 공개키로 서로를 알아본다. 둘만 이어지는 개인용 코드도 있다.
- **기본 포트 범위는 바꿀 수 있다(2026-10-29 추가).** 환경변수 `COWORKER_PORTS`(예: `9000-9010`)로 정한다. 없으면 7700~7799를 쓴다.
- **어느 망이든 자체 암호화한다.** 연결 코드로 연결한 세션이 보낸 것만 받는다.
- **잠깐 끊기면** 보낸 쪽이 보관하고 있다가 다시 보낸다.
- **한쪽만 들어오는 연결을 받을 수 있어도 된다.** 방화벽에 막힌 쪽은 상대에게 먼저 접속해서 자기 앞으로 온 메시지를 가져가고, 받았다고 알려야 상대가 지운다.
- **세션을 다시 열면 연결 코드를 다시 주고받는다.** 연결을 기억해 두는 기능은 써 보고 필요하면 붙인다.

## 메시지가 오면 AI가 반응하는 방법

상대 메시지가 오면 내 AI가 알아서 읽고 답해야, 사람은 지켜보기만 하면 된다.

| 도구 | 방법 |
|---|---|
| Claude Code | **Channels를 쓴다.** `claude --dangerously-load-development-channels server:coworker`로 켠다. 메시지가 오면 세션에 바로 들어가고 AI가 반응한다. 기다리는 동안에는 사용량이 들지 않는다. 다만 직접 만든 채널이라 켤 때마다 개발용 옵션을 붙여야 하고 경고 화면이 한 번 뜬다. Claude Code는 MCP를 채널로 등록했는지 알려 주지 않고, 채널로 등록되지 않은 세션에 보낸 알림은 오류 없이 버린다. 그래서 MCP는 자기를 띄운 Claude Code의 실행 옵션에 `server:coworker`가 있을 때만 채널로 보낸다(2026-10-29) |
| Codex | **대기 도구를 쓴다.** AI가 「메시지 기다리기」를 호출해 두면 메시지가 왔을 때 돌아온다. Codex는 도구 호출을 60초까지만 기다려서 50초(최대 55초)마다 다시 호출하고, 그때마다 사용량이 조금씩 든다 |
| Channels 없이 켠 Claude Code | **대기 도구를 쓰되 시간 제한 없이 기다린다(2026-10-29).** 2분쯤 지나면 Claude Code가 그 호출을 백그라운드로 넘기고 차례를 끝낸다. 메시지가 와서 호출이 끝나면 Claude Code가 AI에게 알리고 AI가 반응한다. 빈 결과로 끝나는 일이 없어서 사람에게 빈 알림이 가지 않는다 |

## AI가 쓰는 도구

| 도구 | 하는 일 |
|---|---|
| 브릿지 열기 | 포트를 열고 연결 코드를 보여 준다. 포트를 지정할 수 있다 |
| 연결하기 | 받은 연결 코드로 상대 세션에 연결한다 |
| 연결 보기 | 연결된 세션 목록과 각각 지금 닿는지 보여 준다 |
| 질문 보내기 | 연결된 세션(여러 개면 지정)에 질문과 지금까지 알아낸 것을 보낸다 |
| 답하기 | 대화에 답을 단다 |
| 메시지 기다리기 | 새 메시지가 올 때까지 기다린다 |
| 합의문 쓰기 | 대화를 마치고 합의문을 양쪽에 남긴다 |
| 사람에게 확인 중 알리기 | 결정이 필요해 자기 사람에게 묻는 동안 상대에게 알린다. 왕복 횟수에 세지 않는다 |
| 브릿지 닫기 | 포트를 닫고 연결을 끊는다 |

질문 하나가 대화 하나다. 한 세션이 여러 대화를 동시에 가질 수 있다.

질문은 한 명, 몇 명, 전체에게 보낼 수 있다(2026-10-29 추가). 여럿에게 보내면 받는 사람마다 대화가 따로 생기고 같은 질문 묶음으로 묶인다. 답 받는 방법은 둘이다. 「모두 답」은 받은 사람 모두에게서 답을 받는다. 「한 명만 답」은 먼저 온 답 하나를 받고, 나머지 사람의 대화를 마감한다. 받는 사람끼리는 서로의 답을 보지 않는다. 대화마다 상태가 있다. 답 기다리는 중, 내 차례, 내 사람에게 확인 중, 상대가 자기 사람에게 확인 중, 사람이 정할 것(왕복 상한에 닿음)이다.

## 안전 규칙

- **보내기 전 확인은 Claude·Codex의 도구 허용 창으로 한다.** 매번 보고 허용해도 되고, 믿을 만하면 「항상 허용」으로 흘려보내도 된다. 기다리기처럼 읽기만 하는 도구는 허용 창 없이 쓰게 설정할 수 있다. 비밀값으로 보이는 내용은 자동으로 막는다.
- **상대 메시지는 참고 자료로만 쓴다.** 상대 메시지를 근거로 파일을 고치거나 명령을 실행하려면 사람 승인이 있어야 한다. 상대가 비밀값이나 파일 내용을 달라고 해도 그대로 따르지 않는다.
- **왕복 횟수에 상한을 둔다.** 대화 하나당 처음 값은 6번이다. 넘으면 사람이 정할 것으로 넘긴다.
- **합의문에는 확인한 사실과 추측을 나눠 적는다.** AI 둘이 서로 맞장구치다 틀린 결론에 합의하는 것을 막기 위해서다.
- **Channels의 원격 실행 승인 기능은 끈다.** 켜 두면 상대가 내 PC에서 명령 실행을 승인할 수 있게 된다.
- **개인 계정의 학습 설정을 확인한다.** 각자 대화를 학습에 쓰지 않도록 설정했는지 확인한다.

## 아직 정할 것

- **포트 범위:** 7700~7799는 기본값이다. 사내 방화벽에 허용을 요청할 범위가 정해지면 `COWORKER_PORTS`로 맞춘다.
- **2차 외부망 방식:** 중간에서 이어 주는 방법을 2차에서 정한다.
- **만드는 언어:** TypeScript(Bun)를 추천한다. MCP 공식 SDK가 TypeScript이고, Claude Channels 예제와 공식 채널 플러그인도 Bun으로 되어 있다.

## 만드는 순서

1. 브릿지 열기, 연결하기, 주고받기: 세션별 포트, 연결 코드, 암호화. 시험은 세 가지로 한다.
   - 같은 PC 안의 Claude와 Codex
   - 집 Mac과 같은 네트워크에 있는 Windows PC: 사내망과 같은 조건에서 직접 연결과 Windows 동작을 함께 확인한다
   - 집 Mac과 회사 Mac mini(Tailscale): VPN과 같은 조건, 즉 다른 네트워크에 있는 IP로 접속하는 경우를 확인한다
   - 회사에서 동료 PC와: 실제 사내망과 VPN에서 확인한다
2. 메시지가 오면 AI가 반응하게 하기: Claude는 Channels, Codex는 대기 도구.
3. 합의문, 왕복 상한, 비밀값 막기.
4. 플러그인으로 묶어 Claude와 Codex에 한 번에 설치되게 하기.
5. 2차: VPN 없는 외부망에서도 연결되게 하기.
