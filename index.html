양쪽 PC ~/.coworker/agreements/ 에 저장

  1. 01

    브릿지 열기

    내 세션에 coworker 브릿지 열어줘라고 하면 포트를 열고 cw1.로 시작하는 연결 코드를 보여 줍니다. 세션마다 7700~7799 사이의 다른 포트로 열립니다.

  2. 02

    코드 보내기

    그 코드를 메신저로 동료에게 보냅니다. 코드는 한 번만 쓸 수 있고 한 시간 뒤 만료됩니다. 옮겨 적다 한 글자라도 틀리면 연결 전에 알려 줍니다.

  3. 03

    연결

    동료가 이 코드로 coworker 연결해줘라고 하면 두 세션이 직접 이어집니다. 사내 IP, VPN 주소, 컴퓨터 이름 순서로 닿는 주소를 찾습니다.

  4. 04

    묻고 답하기

    양쪽 AI가 코드와 문서에서 답을 찾아 바로 답합니다. 주고받을 때마다 각자의 세션에서 사람에게 정리해 알려 줍니다. 그만하라고 할 때까지 계속 듣습니다.

  5. 05

    결정은 사람에게

    선택지, 우선순위, 일정처럼 정해야 하는 건 AI가 정하지 않습니다. 상대에게 사람에게 확인 중이라고 알리고, 내 사람에게 선택지와 추천을 붙여 묻습니다.

  6. 06

    합의문

    끝나면 결론, 확인한 사실과 근거, 추측, 의견이 갈린 점, 사람이 정할 것을 나눠 적은 합의문을 양쪽 PC에 남깁니다.

    설치

    명령 몇 줄이면 됩니다

    필요한 건 Bun 하나. Claude Code와 Codex 중 쓰는 쪽만 설치하면 됩니다.

    1. Bun 설치

      curl -fsSL https://bun.sh/install | bash

      터미널을 새로 열고 bun --version으로 확인합니다.

    2. 플러그인 설치

      Claude Code

      claude plugin install coworker --marketplace BrilliantTiger/ai-coworker-without-me@release

      Codex

      codex plugin marketplace add BrilliantTiger/ai-coworker-without-me@release codex plugin add coworker@ai-coworker-without-me

    3. claude-cw 만들기

      echo "alias claude-cw='claude --dangerously-load-development-channels plugin:coworker@ai-coworker-without-me'" >> ~/.zshrc

      채널 옵션은 설정 파일에 넣을 수 없어서 별칭으로 줄입니다. 터미널을 새로 엽니다.

    4. 켜고 말하기

      claude-cw

      경고 화면에서 「I am using this for local development」를 고르고, coworker 브릿지 열어줘라고 합니다. Codex는 그냥 켭니다.

    1. Bun 설치 (PowerShell)

      powershell -c "irm bun.sh/install.ps1 | iex"

      PowerShell을 새로 열고 bun --version으로 확인합니다.

    2. 플러그인 설치

      Claude Code

      claude plugin install coworker --marketplace BrilliantTiger/ai-coworker-without-me@release

      Codex

      codex plugin marketplace add BrilliantTiger/ai-coworker-without-me@release codex plugin add coworker@ai-coworker-without-me

    3. claude-cw 만들기

      Set-Content "$(Split-Path (Get-Command claude).Source)\claude-cw.cmd" '@claude --dangerously-load-development-channels plugin:coworker@ai-coworker-without-me %*'

      PowerShell과 명령 프롬프트 어디서든 claude-cw로 켭니다.

    4. 켜고 말하기

      claude-cw

      처음 브릿지를 열 때 방화벽 창이 뜨면 「개인 네트워크」에 체크하고 허용합니다.

    방화벽, 연결이 안 될 때, 새 판으로 올리기는 INSTALL.md에 Mac · Windows 따로 적었습니다.

    자주 묻는 것

    궁금한 것들

    서버를 따로 띄워야 하나요?

    아니요. 세션끼리 직접 연결합니다. 같은 사내망이나 회사 VPN이면 바로 됩니다. VPN 없이 다른 네트워크에 있을 때만 중계 서버가 필요하고, 그 소스와 배포 파일이 저장소에 들어 있습니다.

    상대 AI가 내 PC에서 뭔가 실행할 수 있나요?

    아니요. 상대 메시지는 참고 자료로만 씁니다. 파일을 고치거나 명령을 실행하려면 내 사람이 승인해야 하고, 상대가 내 PC의 실행을 승인하는 기능은 켜지 않습니다.

    회사 방화벽에 막히면요?

    두 PC 중 한쪽만 들어오는 연결을 받을 수 있어도 됩니다. 막힌 쪽은 상대에게 먼저 접속해 자기 앞으로 온 메시지를 가져갑니다. 양쪽 다 막혀 있으면 사내 IT에 PC끼리 TCP 7700~7799를 허용해 달라고 요청하면 됩니다.

    무엇이 PC 밖으로 나가나요?

    AI가 보내는 질문, 배경, 답, 알림, 합의문과 세션 이름, 연결 코드에 든 주소뿐이고, 연결한 세션에만 갑니다. 사용 통계나 원격 수집은 없습니다. 자세한 건 PRIVACY.md에 있습니다.

    비용이 드나요?

    무료 오픈소스(MIT)입니다. 각자 쓰는 Claude나 Codex의 사용량만 듭니다. Claude Code를 채널로 켜면 기다리는 동안에는 사용량이 들지 않습니다.
