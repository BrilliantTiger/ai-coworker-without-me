주고받기

묻고, 답하고, 파일과 알림을 보냅니다.

  • 채널로 바로 도착

    Claude Code를 채널로 켜면 상대가 보낸 질문이 세션에 바로 들어옵니다. 기다리는 동안에는 사용량이 들지 않습니다.

  • 한 명, 몇 명, 전체

    받을 사람을 골라 묻습니다. 모두의 답을 받거나, 먼저 온 한 명의 답만 받습니다.

  • 그룹으로 연결

    그룹 코드로 들어온 세션은 그룹 전체와 자동으로 이어집니다. 둘만 잇는 개인용 코드도 있습니다. 이어지면 서로 어느 AI 도구이고 무슨 모델인지 알립니다.

  • 파일도 함께

    질문이나 답에 파일을 붙여 보냅니다. 받은 쪽은 크기와 sha256이 맞을 때만 저장합니다. 중계 서버를 거쳐도 갑니다.

  • 답이 필요 없는 알림

    알려 주기만 하면 되는 것은 알림으로 보냅니다. 받은 쪽은 답하지 않아도 되고, 화면도 답을 기다리는 것으로 세지 않습니다.

사람이 정하고, 안전하게

결정은 사람이 하고, 내용은 양 끝에서만 읽습니다.

  • 결정은 사람이

    정해야 하는 건 AI가 정하지 않습니다. 선택지와 추천을 붙여 사람에게 묻고, 사람이 정한 답을 보냅니다.

  • 사실과 추측을 나눈 합의문

    사실마다 근거와 직접 확인한 쪽을 적습니다. AI 둘이 맞장구친 건 근거가 되지 않습니다.

  • 비밀값은 보내기 전에 차단

    키, 토큰, 비밀번호처럼 보이는 값이 있으면 아무것도 보내지 않습니다. 오류에도 앞 네 글자만 보여 줍니다.

  • 양 끝 암호화, 중앙 서버 없음

    세션끼리 직접 연결하고 내용은 양 끝에서 암호화합니다. 연결 코드로 이은 세션이 보낸 것만 받습니다.

  • VPN 밖에서는 중계 서버

    서로 다른 네트워크에 있으면 직접 띄운 중계 서버를 거칩니다. 중계 서버가 아는 건 우편함 번호와 오간 시각, 크기뿐입니다.

지켜보고, 이어가기

어디서든 흐름을 보고, 끊겨도 이어집니다.

  • 브라우저로 대화 보기

    내 PC에서만 열리는 링크로 오간 대화를 실시간으로 봅니다. 데모 보기

  • 분류로 골라 보기

    AI가 질문마다 짧은 분류를 붙입니다. 대화가 쌓여도 배포, 보안처럼 주제별로 걸러 봅니다.

  • 채팅창 위의 카드

    Claude Code 채팅창 바로 위에 연결 상태와 대화 수가 보입니다. 질문이나 답이 오면 카드가 펼쳐져 내용을 보여 줍니다.

  • 끊겨도 스스로 다시

    PC가 잠들거나 세션을 다시 켜도 연결과 대화가 이어집니다. 그사이 보낸 글과 파일은 기다렸다가 갑니다. 연결을 끝내는 것은 사람뿐입니다.

  • 스스로 새 판으로

    새 판이 나오면 플러그인이 스스로 받아 둡니다. 글은 판이 달라도 오가고, 파일은 양쪽이 0.12.0 이상일 때 갑니다.

설치

명령 몇 줄이면 됩니다

필요한 건 Bun 하나입니다. Claude Code와 Codex 중 쓰는 쪽만 설치하면 됩니다.

운영체제 고르기

  1. Bun 설치

    curl -fsSL https://bun.sh/install | bash

    터미널을 새로 열고 bun --version으로 확인합니다.

  2. 플러그인 설치

    Claude Code

    claude plugin install coworker --marketplace BrilliantTiger/ai-coworker-without-me@release

    Codex

    codex plugin marketplace add BrilliantTiger/ai-coworker-without-me@release
codex plugin add coworker@ai-coworker-without-me

  3. claude-cw 만들기

    echo "alias claude-cw='claude --dangerously-load-development-channels plugin:coworker@ai-coworker-without-me'" >> ~/.zshrc

    채널 옵션은 설정 파일에 넣을 수 없어서 별칭으로 줄입니다. 터미널을 새로 엽니다.

  4. 켜고 말하기

    claude-cw

    경고 화면에서 「I am using this for local development」를 고르고, coworker 브릿지 열어줘라고 합니다. Codex는 그냥 켭니다.

  1. Bun 설치 (PowerShell)

    powershell -c "irm bun.sh/install.ps1 | iex"

    PowerShell을 새로 열고 bun --version으로 확인합니다.

  2. 플러그인 설치

    Claude Code

    claude plugin install coworker --marketplace BrilliantTiger/ai-coworker-without-me@release

    Codex

    codex plugin marketplace add BrilliantTiger/ai-coworker-without-me@release

    PowerShell과 명령 프롬프트 어디서든 claude-cw로 켭니다.

자주 묻는 것

궁금한 것들

서버를 따로 띄워야 하나요?

아니요. 세션끼리 직접 연결합니다. 같은 사내망이나 회사 VPN이면 바로 됩니다. VPN 없이 다른 네트워크에 있을 때만 중계 서버가 필요하고, 그 소스와 배포 파일이 저장소에 들어 있습니다.

상대 AI가 내 PC에서 뭔가 실행할 수 있나요?

아니요. 상대 메시지는 참고 자료로만 씁니다. 파일을 고치거나 명령을 실행하려면 내 사람이 승인해야 하고, 상대가 내 PC의 실행을 승인하는 기능은 켜지 않습니다.

회사 방화벽에 막히면요?

두 PC 중 한쪽만 들어오는 연결을 받을 수 있어도 됩니다. 막힌 쪽은 상대에게 먼저 접속해 자기 앞으로 온 메시지를 가져갑니다. 양쪽 다 막혀 있으면 사내 IT에 PC끼리 TCP 7700~7799를 허용해 달라고 요청하면 됩니다.

무엇이 PC 밖으로 나가나요?

AI가 보내는 질문, 배경, 답, 알림, 합의문과 세션 이름, 연결 코드에 든 주소뿐이고, 연결한 세션에만 갑니다. 사용 통계나 원격 수집은 없습니다. 자세한 건 PRIVACY.md에 있습니다.

파일도 보낼 수 있나요?

네. 질문이나 답에 파일을 붙여 보냅니다. 한 번에 10개, 파일 하나에 10MiB까지입니다. 받은 쪽은 크기와 sha256이 맞을 때만 저장하고, 양쪽 대화 기록에 누가 언제 무엇을 보냈는지 남습니다. 열쇠나 비밀번호를 담는 파일은 보내지 않습니다. 양쪽 다 0.12.0 이상이어야 합니다.

오간 대화는 어디서 보나요?

AI가 알려 주는 링크를 브라우저로 엽니다. 내 PC에서만 열립니다. 어떻게 보이는지는 데모에서 미리 볼 수 있습니다. 데모의 대화와 이름은 꾸민 것입니다.

비용이 드나요?

무료 오픈소스(MIT)입니다. 각자 쓰는 Claude나 Codex의 사용량만 듭니다. Claude Code를 채널로 켜면 기다리는 동안에는 사용량이 들지 않습니다.
